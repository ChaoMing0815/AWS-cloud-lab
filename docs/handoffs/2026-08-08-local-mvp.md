## 最新決策與衝突處理

1. 產品是「共演計劃」多人 AI 文字故事遊戲；WordPress 不是目前主題。
2. Tier 0–5 必須沿用同一產品逐層演進，不是選擇題。
3. 本機先使用 Vanilla JS＋FastAPI＋memory repository；正式資料庫預計 private PostgreSQL，但 ADR 尚未核准。
4. LLM 只負責敘事，不得擲骰、修改規則結果或直接控制 canonical state。
5. AWS 部署仍暫停；不得因本機 MVP 有進展就跳過 account plan、Budget、估價、principal、Region 與清理關卡。
6. 禁止再建立／加入 AWS Organizations；不建立長期 Access Key，不授予應用程式 `AdministratorAccess`。

## 驗證指令

```bash
cd backend
../.venv/bin/python -m pytest

cd ../web
npm test
```

若 shell 找不到 `npm`，使用 Codex 工作區隨附 Node.js 執行 `node --test`；不要因此安裝未經需要的全域套件。

啟動本機頁面：

```bash
.venv/bin/python -m uvicorn app.main:app --app-dir backend --reload
```

開啟 `http://127.0.0.1:8000/`。驗證後停止伺服器，不要把本機服務常駐狀態當作完成證據。
